# H3 共用制作流程

默认从[本地 ComfyUI](comfyui-local.md)开始；使用另一台机器时，选择[远程 ComfyUI](comfyui-remote.md)。模板只描述素材、生成与剪辑方法，连接地址和文件传输由所选运行方式处理。

## 运行前后

1. 核对模型、节点、工作流分支及参考图／音频绑定；先测试一个短片段。有续接要求的模板还需测试真实续接。
2. 提交实际 API 工作流，保存任务 ID、输入、参数和输出记录。断线先查询原队列与历史，避免重复生成。
3. 检查人物、动作、画风、声音、帧数和接缝，通过后再拼接与后期。

Agent 可用 `/object_info` 检查节点，向 `/prompt` 提交 API 图，通过 `/queue`、`/history/<prompt_id>` 查询任务；具体接口见 [ComfyUI 官方文档](https://docs.comfy.org/development/comfyui-server/comms_routes)。图片、视频和音频的导入能力以实际节点为准。

## 记录什么

- **环境**：运行方式、系统、GPU／显存、ComfyUI 与节点版本、权重及配套模型。
- **参数**：采样方式、步数、种子、分辨率、帧数、帧率和加速设置。
- **结果**：实际时长、音轨、耗时、失败与修复；未知项标明待补。

视频推理在用户自己的设备或所管理的服务器上完成；图片、声音及可选预处理可用在线服务，并注明外部依赖。后期超分与 H3 原生输出规格分别记录。

权重许可见 [H3 模型卡](https://huggingface.co/MiniMaxAI/MiniMax-H3)。各模板的额外依赖和验证状态以模板说明为准。

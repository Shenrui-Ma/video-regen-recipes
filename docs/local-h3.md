# 本地 H3 制作

视频在个人电脑或自托管 GPU 服务器上生成。当前仓库还没有可运行模板或安装脚本。
参考图、声音等辅助素材可以使用本地工具或在线服务；说明运行位置与素材上传去向即可。

## 每份模板记录这些信息

- 硬件：系统、GPU、显存与内存。
- 环境：ComfyUI 和节点版本，H3 模式、权重来源、版本或哈希、精度及配套模型。
- 参数：采样方式、步数、种子、分辨率、帧数、帧率与加速设置。
- 结果：实际时长、音轨、耗时、失败与修复。

## 运行前后检查

1. 检查工作流真正启用的分支，替换旧路径，确认模型与节点齐全。
2. 核对每张参考图、每段声音的用途及绑定；画布连线不代表输入已生效。
3. 保存实际输入、任务 ID 和输出。中断后先查队列与历史，避免重复生成。
4. 检查人物、动作、画风、声音和衔接，再剪辑。目标时长不能代替实测时长。

官方托管的 **Regenerate-2K 云端视频再生成不属于当前路线**；后续视频生成也应本地／自托管执行。可选 Context-IR 预处理需注明外部依赖。普通超分输出不能标为 H3 原生同分辨率生成。

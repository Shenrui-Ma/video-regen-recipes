# 本地 ComfyUI（默认）

ComfyUI 和模型运行在自己的电脑上。先准备模板要求的节点、模型和显存，再按模板生成。

1. **连接**：启动本机 ComfyUI，使用它实际显示的地址。Agent 也在同一台电脑上运行时，连接该本机地址；若 Agent 在其他机器，按[远程版](comfyui-remote.md)处理。
2. **准备素材**：在本机项目目录整理图片、视频和音频，通过节点支持的导入方式绑定素材。工作流中的模型名称和素材引用需对应本机实际文件。
3. **生成**：按[共用流程](local-h3.md)检查输入、提交任务并保存任务 ID。模板要求的续接、裁帧等规则保持不变。
4. **取回结果**：根据任务记录找到本机输出，复制到项目目录，检查后剪辑导出。

本机路径只保存在自己的运行配置中，公开模板使用相对路径或占位符。连接说明不包含模型安装器或自动执行器；模板的特殊依赖以其工作流说明为准。

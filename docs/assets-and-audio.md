# 角色图像与声音素材

视频生成暂时聚焦本地 H3；图像、语音、音乐与其他辅助模态按创作需要选择工具。此文是素材规范，具体自动化配方仍在整理。

## 让参考素材各司其职

| 素材 | 作用 | 需要说明 |
|---|---|---|
| 身份图／角色设定 | 外貌、服装、标志性特征 | 哪些特征必须保持，哪些允许改动 |
| 场景／风格参考 | 空间、光线、色彩与画法 | 项目整体规则与场次例外 |
| 动作／站位参考 | 姿态、方向、人物关系 | 主体对应、视角与可接受偏差 |
| 首帧／尾帧／中间帧 | 具体构图或连接条件 | 对应的片段、位置与输入方式 |
| 声音参考 | 音色、语气、节奏或信号复用 | 说话者、用途、授权及实际文件 |

同一个文件可以承担多个用途，但不要让模型自行猜测。提示词中的“图1”是本次输入的编号，不是跨项目的角色身份。

## 可复用的角色资产包

从一张清楚的角色图开始，按镜头补充所需的多视图、表情或服装。把原始设定与模型专用提示词分开保存，并记录素材版本与来源。

长期角色库放在自己的工作区；每次项目绑定实际使用的版本，保留必要快照。不要把私人角色库直接放进公开模板目录。

可选工具包括本地 ComfyUI 图像工作流、NovelAI、GPT Image，以及其他能产出合适图像的工具。是否好用取决于它能否提供目标镜头所需的身份、构图和风格条件。

## 声音分开管理

- **临时配音**：试台词长度和表演节奏。
- **音色或表演参考**：为 H3 或语音工具提供声音特征。
- **最终对白**：成片使用的人声。
- **环境声与效果声**：场景、动作和声音连接。
- **音乐**：单独说明生成、授权素材或后期添加方式。

没有背景音乐不等于没有声音。若 H3 只返回混合音轨，后期换音乐时需要明确怎样保留或重新制作对白；不能只叠加新音乐就认为完成。

官方 Ref2VA 规范中的 `detailed_description` 承载画面、动作与对白，不应当作“禁止字幕”开关清空。作者经验性写法与正式提交格式分别保留，实际文字和声音仍需检查。[官方参考规范](https://github.com/MiniMax-AI/MiniMax-H3/blob/main/skills/h3-prompt-writing/references/ref-en.txt)

## 公开素材

只分发自有或明确允许再分发的图像、声音、音乐和字体；否则保存来源链接与输入说明。模板说明记录素材的使用范围，具体模型和服务的条款独立适用。

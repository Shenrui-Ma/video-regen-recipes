## 离线复查

在仓库根目录运行，不需要密钥，也不会生成图片：

```bash
python3 -m unittest discover -s skills/gpt-image2-reference-images/tests -v
python3 -m unittest discover -s skills/novelai-reference-images/tests -v
```

本次通过 32 项离线测试：GPT Image 2 为 12 项，NovelAI 为 20 项。脚本使用 Python 标准库；测试覆盖具体输入错误、异常响应、重复提交与跨任务响应错配，不代替真实服务端兼容性和画面验收。

## 验收情景

| 输入或异常 | 应有行为 |
| --- | --- |
| 指定 SDXL，却选到 Anima LoRA | 匹配失败，重新找兼容版本，不靠文件名猜 |
| 本地有模型、远程实例没有 | 在执行主机补齐并核验，不能当作已安装 |
| 参考图只有路径文字，没有附件或输入边 | 补全实际绑定，不声称参考已生效 |
| 下载中断、Range 返回完整文件 | 重新写入，不追加造成损坏 |
| 服务可能已收到生成任务，但连接中断 | 标记结果未知，查询本任务，不自动重发 |
| 响应已保存、图片提取失败 | 只恢复本地结果，不重复付费 |
| 图片尺寸正确，但身份或动作错误 | 内容验收失败，不自动进入视频生成 |
| Agent 没有看图工具 | 保留技术检查结果，标记画面待检查 |
| NovelAI 模型 ID 或参考配置缺少官方依据 | 报告具体缺项，不猜 ID、不丢弃参考输入继续 |

以上是执行验收标准；尚未用不同能力的 Agent 进行成功率评测。后续需分别补充真实账户、模型／节点版本、GPU 环境、图像结果及人工验收记录。

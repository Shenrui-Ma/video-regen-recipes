# 制作配方的内容约定

本文件是首批模板的编写指南。仓库当前处于初始化阶段，以下文件结构是约定示例，尚无通用执行器或强制 schema。

## 每份模板留下完整的制作方法

```text
templates/<template-id>/
├── README.md          # 效果、素材、步骤与可改范围
├── sources.md         # 作者、参考作品、许可与方法来源
├── prompts/           # 原稿与实际提交稿
├── workflows/         # 本地H3的工作流或固定版本引用
├── assets/            # 仅可再分发的小型必要素材
└── evidence/          # 环境、输入、结果、失败与修复记录
```

共用的 H3 工作流可以集中在 `workflows/comfyui/h3/`，模板引用明确版本。公共角色或音频准备方法放在 `shared/`；避免把相同教程复制到每个模板。

## 必须回答的问题

| 内容 | 需要交代 |
|---|---|
| 想做的效果 | 动作、节奏、画风、镜头或叙事，哪些构成模板的核心 |
| 输入素材 | 角色槽、场景、动作、声音和关键帧，各自用途和文件要求 |
| 可以修改什么 | 自由修改项、需要重新准备的输入、需要重设计的规则 |
| 怎样执行 | H3模式、实际工作流、环境与参数，图像/声音的可选来源 |
| 怎样做后期 | 选片、衔接、对白、音乐、字幕与输出规格 |
| 怎样返修 | 哪些输入或生成段受到影响，如何复用其他结果 |
| 怎样证明 | 真实运行环境、日期、产物、成本口径和已知限制 |

## 镜头、生成段与时间线

镜头描述观众看到的画面；生成段是一项实际模型任务；时间线规定片段的裁切与连接。一个生成段可以包含多个镜头，一个连续镜头也可能由多个生成段续接。

保留稳定 ID 和对应关系。改变某个镜头时，重新检查它所在的生成段及前后衔接，不默认整片重做。

## 状态与证据

| 状态 | 含义 |
|---|---|
| 线索 | 有原始案例，但制作条件尚不完整 |
| 整理中 | 正在补齐素材、步骤与执行配置 |
| 已验证配置 | 具体环境、输入与输出已经完成复现并记录 |
| 待修复 | 原有配置因依赖或其他变化失效 |

“已验证”必须指向具体配置。支持加载 Skill、能够连接工具或拥有一条漂亮样片，都不能单独证明其他角色或环境可以复现。

验证记录建议包含：模板版本、工作流哈希、模型与节点版本、角色和参考素材哈希、实际输入、种子、输出规格、生成候选数、总耗时，以及是否使用在线图像/声音或托管增强。

成本和速度写清统计范围，保留失败与返工。公开示例优先提供一个基础版本与一个不同角色或场景的版本。

## 首批贡献范围

优先整理本地 H3 的番剧场景、角色短片和风格化动画。辅助模态可以混合本地与在线工具。一个充分验证的配置即可作为模板主路线，不要求支持所有 Agent、设备或模型组合。

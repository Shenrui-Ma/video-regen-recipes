# 维护者复现测试

测试目标是验证模板说明是否足够完整，使 Agent 无须临时寻找额外解决方案即可完成视频制作。每轮选择一个模板、一个角色或创作需求，在新会话中使用[复现测试提示词](reproduction.prompt.md)。

例如，告诉测试 Agent：

> 按 `docs/testing/reproduction.prompt.md` 的规则，测试《一点一滴刺痛我的心》模板：用【角色名】生成跳舞视频，验证能否仅凭模板完成一键复刻。

Agent 先定位模板、记录版本与初始环境，再按说明执行。遇到未覆盖的故障就停止受影响步骤并留证；已写明的模型查找、安装和恢复步骤可以执行，不把正常依赖准备误判为模板外补救。

每次报告对应一个模板及一次测试配置。相同模板更换角色、系统、模型或思考强度时，另开记录；已有环境测试与从未部署过的新环境测试分开标注。

可以提交脱敏后的测试报告作为 Issue，写清版本、环境、卡住的步骤、错误及缺少的说明。原始日志、凭据和未获准公开的素材留在测试者本地；不要自动上传或发送。

测试与修复分开进行。修复后固定新版本，用新会话按相同要求复测；测试过程中接受的额外人工指导也要记录，不能算作模板独立复现通过。本文件是维护者测试入口，不改变普通用户创作时的执行方式。

投稿作者把制作经验整理成模板时，使用[模板制造提示词](../authoring.prompt.md)；制造完成后冻结候选版本，再回到本文件进行独立复测。

# 角色展示合集

说出喜欢的角色和主题，由 Agent 准备图片、生成动态片段并剪成合集。

- [角色图像合集](image-collection/README.md)：ComfyUI 生图，制作缩放展示或静态溶解视频。
- [角色视频合集](video-collection/README.md)：ComfyUI 首帧 → H3 动态片段，也支持原图接对应视频。
- [泳装动态立绘视频集](swimsuit-live-portraits/README.md)：沿用具体合集节奏的细分配方。

共同使用 [ComfyUI 参考图 Skill](../../skills/comfyui-reference-images/SKILL.md) 和 [合集剪辑 Skill](../../skills/character-showcase-editing/SKILL.md)。

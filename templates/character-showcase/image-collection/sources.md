# 来源与验证

配方与工程整理：**Shenrui Ma（四倍体果蝇）**。

剪辑依据为作者提供的角色展示工程包、PR 序列提取参数及两套图片合集脚本：缩放模糊版与静态溶解版。公开版抽取通用曲线、时间线和处理逻辑，新增可配置输入与输出保护。原始 PR / XML 和聊天记录不随此模板分发。

历史资料证实两种 11 图、65 秒剪辑方案。2026-09-11 整理时核对归档完整性、JSON / Python 结构与参数；没有重新观看素材、做视觉检查、运行生图或渲染。公开版的 ComfyUI 生图接入、6 图默认及通用剪辑脚本仍需在实际环境验收。

生图依赖采用 [ComfyUI](https://github.com/Comfy-Org/ComfyUI) 与所选模型各自的许可；工作流从 [配套库](https://github.com/Shenrui-Ma/shenrui-comfyui-toolkit) 固定版本获取。新用户自己的角色图、模型与配乐不随模板提供。

# 两种图片合集

| 项目 | A：缩放与模糊 | B：静态纯溶解 |
| --- | --- | --- |
| 前景 | 缩放、由糊变清 | 固定 104%，没有缩放或平移 |
| 转场对象 | 只溶解前景 | 整个竖屏合成画面 |
| 背景 | 前景转场结束后 1 帧硬切 | 随整画面一起溶解 |
| 总长 | 均分既定总帧数，转场不再扣总长 | 输入时长补偿重叠后得到目标总长 |
| 首尾 | 默认尾部 1 秒音画淡出 | 默认首图 50 帧淡入，无尾淡出 |

历史 A / B 均有 11 图、65 秒案例；模板默认 6 图、36 秒是适合新请求的复用设置。修改张数或时长会重算边界，不沿用旧文件数量。

## 原始缩放参数

60fps 时间基准：`0f:312% → 123f:222% → 186.268f:222% → 310.733f:104%`。区间使用历史 cubic Hermite，切线依次为 `-6.120207911535838、-27.796610169488954、-27.796610169488954、-9.562927856583157`，作用于归一化区间，不再乘帧间距。动画结束后保持 104%。

背景 236%、模糊 40；前景模糊由 45 到 0，结束于 91.117f。A 前景 25 帧溶解：名义边界前 12 帧到后 13 帧；背景在边界后 14 帧切换。分辨率和 fps 改变时，原始值按实现的时间/画布基准转换，不把 PR 参数当通用像素单位。

A 边界 `round(i * total_frames / N)`。B 每路的理想帧长为 `(total_frames + (N-1)*transition_frames)/N`，执行器进行整数分配，最后总帧数应与计划一致。

## 音频与非方形图片

`source_start_seconds` 是音乐源裁切起点，`output_start_seconds` 是在成片中的入场点；前者不意味着开头静音。提供配乐时默认连续播放、-7dB，可修改音量或选择不循环。没有配乐则 `audio.mode=silent`。

历史脚本会将素材缩成方形。公开执行器改为等比适配：`contain` 保全图，`cover` 允许裁切；配合居中前景和填满背景。Pillow / FFmpeg 与 Premiere 的模糊、缩放和羽化实现不同，本模板不承诺逐像素一致；历史白色 alpha mask 模糊也不能算真实边缘羽化。

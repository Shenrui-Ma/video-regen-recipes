# 角色图像合集

**说一句话，用喜欢的角色生成一支图像展示视频。**

> 给我做一支角色图像合集：角色是……，主题是海边旅行。

Agent 用 ComfyUI 生成一组角色图，再加上缩放、模糊背景、转场和配乐。也可以说“纯溶解，不要缩放”，或提供自己的图片。

- 默认：6 张图、36 秒、1080×1920、60fps；没有配乐时先输出无声版。
- 需要：本地 ComfyUI、匹配的生图模型、Python、Pillow 和 FFmpeg。图片合集不需要 H3。
- 可改：角色、服装、场景、张数、时长、排列、转场和配乐。

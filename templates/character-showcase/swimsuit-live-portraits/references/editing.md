# 剪辑规格

使用[公共角色展示剪辑 Skill](../../../../skills/character-showcase-editing/SKILL.md)，输入为已经绑定版本的 8 个动态视频。模板参数不是一个可直接执行的旧脚本；先转换成公共工具的请求格式，再执行。

| 参数 | 默认 |
|---|---|
| 画布 | 1080×1920、60fps、SAR 1:1 |
| 构图 | 前景保比例 fit 居中；背景是同一时刻画面的 cover 裁切并模糊 |
| 背景模糊 | 高斯 sigma 35，历史 FFmpeg 实现 steps 2 |
| 开头 | 首段运动画面前 0.5 秒，在 sigma 30 模糊分支与清晰分支之间线性混合 |
| 相邻转场 | 0.2 秒交叉溶解；相应原声音轨 `acrossfade` |
| 结尾 | 最后 1 秒淡至黑，原声和 BGM 一起淡出 |
| 声音 | 自然原声保留；用户 BGM 从源第 0 秒、成片第 0 秒开始，增益 -12dB |
| 交付 | H.264、yuv420p、AAC 48kHz 双声道；历史母版约 100Mbps，新项目按质量/体积选择 |

开场历史实现是两个**同时运动**的画面分支混合，不是逐帧减小 sigma，也不是在视频前插入静图。视频片段不叠加图片模板的放大缩小运动。

1. 先裁视频 `[start,end)`，再按 `speed` 改 PTS；音频取相同区间并应用同倍率 `atempo`。
2. 视频输入统一 timebase、fps、SAR、pixel format。原声不足补等长静音，没有原声的镜头也占同样的时间线位置；不能让声音串到下一个角色。
3. 第 `i` 段实际可用时长为 `d_i=(end_i-start_i)/speed_i`。连续 8 段、转场 `x=0.2` 时：`T=sum(d_i)-7*x`。第一个转场 offset 为 `d_1-x`，之后每次累计下一段时长减一个 x。
4. 原案例浮点时间线约 62.149206667 秒，最终视频记录为 3729 帧，即 62.150 秒。帧对齐误差不靠截掉一段尾帧修正，也不硬写成精确 60 秒。
5. 最后一个输出帧应到达黑场。离散时间的淡出终点按最终帧网格计算，音频同步。历史脚本用 `T-1-1/60` 作为一秒淡出的起点；修改总长/fps 时重算。
6. -12dB 仅作用于 BGM，原声不随之一起变小；混合后防止峰值溢出。未提供 BGM 时交付自然声版本。不要把历史案例歌曲作为仓库自带或自动下载的素材。

本模板默认不把视频补到 61 秒。历史案例的“至少 61 秒”条件在 v4 没有触发；保持这个事实，只有用户要求目标时长时才显式记录定格/循环等补时策略。

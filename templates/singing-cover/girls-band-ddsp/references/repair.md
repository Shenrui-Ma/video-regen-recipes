# 局部返修与版本权威

## 最小返工单位

为每处记录 repair ID、父 stem SHA、目标词/现象、源入出点、时间线半开采样区间 `[start,end)`、声道、参数、输出 SHA、内容听审与局部保持检查。时间转换采用明确的采样舍入规则；不要从截图估秒后覆盖旧轨。

先分清声部归属、多声/声相干扰、F0、音素错误和混音问题。优先顺序是：候选映射 → raw/noreverb 选择 → L/R/Mid/Side 干声比较 → 单声部短段转换 → F0/音区单变量试验 → 目标音色音素供体 → 经本次明确接受的原唱窄范围替换。ASR 识别或相关性上升不等于听感正确；强音唱错元音通常不是阈值问题。

每次先验收干声，再叠加伴奏做短预览，最后回填全长 stem。保留失败原因和拒绝分支，不把所有试验写成成功经验。

## Billie Jean：两个音节不等于整个窗口

历史先讨论 01:17 与 02:38 的两声 hey hey，最终局部替换脚本范围收窄为**只动 01:17，02:38 保持**。公开模板不继承历史授权；新任务要再次确认是否接受原唱残留，并披露不是全程目标角色声音。

历史 44.1 kHz 的两个 mask 为 `[3384014,3407298)` 和 `[3414663,3434199)`，对应约 76.735–77.263 秒和 77.430–77.873 秒。总长 42820 samples，间隙 7365 samples 未动。这些坐标只属于对应父文件，绝不能无条件套到不同录音/剪辑版。

从未转换的**分离总人声**取替换素材，不剪整首原混音。逐音节匹配 RMS、限制增益、短等功率交叉淡化；历史使用 ±9 dB 上限与约25 ms 边缘，仅作起点。不要扩大到整段试听窗口，也不要重复叠加旧音节。mono/stereo 映射需明确，不能默认折成单声道。

历史脚本只断言导出前浮点数组 mask 外差为零，没有完成导出 PCM24 再解码比较，不能扩大成“已验证导出后无变化”。新任务应对同格式父 stem 和导出再解码的新 stem 做 mask 外逐样本比较；量化差异单独说明。再次母带处理会改变全曲，不应在 master 层要求相同断言。

旧单声道重推、高频音素保护、主唱事件重分类、干声探针及 donor 试验均有诊断价值，但不代表各版均获接受。高频注入可能泄漏原唱；若不能接受原声保留，应停止该分支而非默默混入。

## Starboy：尾音与 FX 分开

初始 +12 推理的混音 v3 不等于原调；原调 r2 是重推，和声阈值 -85 的 r3 是独立分支。自动四尾音修复 r4/r5/r6 与后续手动 Audition 工程不是同一时间线。不能拿旧自动切点覆盖手动调整。

返修先验证替换词干声，删除旧 lead/backing 对应事件，再加新尾音。记录“删除 mask”和“新 FX 尾巴窗口”两个范围，新混响尾可能合法延伸到 mask 外。只证明 mask 外不变不能证明词唱对了。

如果请求“纯回声”，关闭混响、早期反射、扩散等额外处理，不是只把混响调小。资料中的一版为 delay380 ms、feedback22%、dry100%、首个 wet15%、spread90%、trash0%；在44100 Hz 下延迟16758 samples，第 n 次回声增益 `0.15 * 0.22**(n-1)`。这些是特定后期快照，不是 DDSP 参数，也不是新混音默认值。

检查立体声回声时减去 dry 再分析湿路；中置 dry 会让全轨 L/R 相关性很高。程序化延迟/混响不能冒充 Audition 原生插件完全等价。

## 手改工程不被脚本覆盖

用户手工保存的工程成为导出权威。冻结其哈希，按实际 source in/out、start、clip/track gain、mute、split、fade 与 automation 重建；不能回到旧“整曲配方”抹掉编辑。不能仅按文件修改时间把 autosave、backup、主 SESX 判成同一音频语义。

需要 DAW 工程时在新副本放启用 FX 打印轨和静音 dry/reference，防止 dry 重复叠加。打印全长、样本点对齐、保留可解析媒体引用，再实际打开 DAW 检查波形和缺媒体。资料有 XML 不等于公开版附完整可编辑工程；本模板不附 SESX 或媒体。

不支持的插件/声像/包络语义不能猜，应由原 DAW 导出或与 reference bounce 比较。渲染前后源工程哈希应一致；变了就重读。样本峰值 dBFS 不是真峰值 dBTP，硬切也需边界听审，不擅自加用户没要求的淡出。

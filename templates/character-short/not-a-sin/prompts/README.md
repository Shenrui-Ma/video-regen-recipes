# 提示词：历史稿与参数化稿分开

- `historical-seg01.txt`：原制作目录中首段提示词的字节级副本，SHA 与原清单相符。它证明历史写法，不单独证明终版每个远端任务都提交了同一字节版本。
- `ref2va.template.txt`：本次公开整理的通用稿。不是历史提交稿，也没有重新进行 GPU 验证。

历史控制器沿用了基础段 prompt 文件。在半速参考拆分后，历史稿仍写着原速段长，例如175帧／7.291667秒；对于177帧慢速子段尤其不一致。不得把这个继承缺陷复制为通用规则。新项目按**当前可见慢速子段**填写帧数与时长，并保留此改动的记录。

另有三个规范化改动：

1. 历史 `fully_preserved_except_main_performer` 是自写描述，不是官方枚举。通用稿用 `partially_preserved` 并解释只替换演员。
2. 背景 “immutable plate” 是软提示，不是遮罩或像素锁。通用稿仍积极描述亮度、布局与文字保留，但验收必须看实际输出。
3. 历史 `[audio reuse]`／`fully_copy` 不能证明原音轨字节复制。本稿按真实绑定使用 `[audio reference]`；最终音乐由后期回装。若没有音频连线，删除 `<Audio 1>` 的定义、retention项和 summary 中的 audio reference，而不是留下悬空编号。

## 变量绑定

- `CHARACTER_DESCRIPTION`：角色身份与可见外观，不含未经素材支持的特征。
- `OUTFIT_DESCRIPTION`：本次固定服装及配饰；不要把源片服装标签直接移植过来。
- `BACKGROUND_ANCHORS`：当前参考的背景配色、亮度、标志和构图保留目标。
- `VISIBLE_FRAMES` / `DURATION_SECONDS`：当前慢速生成子段的公开可见长度，非原速整段长度，也非包含隐藏前缀的采样长度；由计划计算。

图像仅用于身份时，定义为 `<Subject 1>` 的角色参考图，不把它误写成严格第一帧。`<Video 1>` 是本子段的动作与剪辑来源。图号、视频号与音频号分别编号，提交前核对实际输入顺序。

相同 prompt 与 Seed 不保证跨环境像素一致。每次保存渲染后的实际文字，检查无剩余 `{{...}}`、旧人名、旧时长和错误服装，再提交。

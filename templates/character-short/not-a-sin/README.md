# XX不是罪过

**用自己的角色，重演参考视频的动作与音乐节奏。**

由 **Shenrui Ma（马深睿）** 在《银狼不是罪过》的制作中整理，受《DeepSeek不是罪过》启发。[来源与署名](sources.md)

> 银狼案例已有约 97.6 秒的历史成片。目前提供制作说明、提示词与参数；完整执行包整理中，新角色复现待验证。

适合单人表演、固定服装，尽量保留参考动作、构图和节奏。逐段换装、改场景或换歌需要另备素材、重新对时；背景与细节仍需检查。

## 准备什么

- **素材**：一张清晰角色图、单人驱动视频、与源片同步的完整音乐，均需有使用权限。图片和声音的制作工具不限。
- **环境**：本地或自托管 ComfyUI + H3 Ref2VA、联合音视频 Motion Context 续接实现、RIFE、FFmpeg/ffprobe。普通 H3 节点不自带本配方的全部续接能力，见[工作流说明](workflows/README.md)。
- **工作目录**：在模板外保存素材、生成结果与运行记录。

## 怎么做

**RIFE 半速参考 → H3 串行续接 → 拼接并恢复原速 → 回装音乐 → 可选补帧、超分。**

1. **划分参考片**：按动作与切点建立帧区间 `[start, end)`，再拆为 H3 子段。银狼案例为 14 个制作段、27 个生成子段。
2. **制作半速参考**：保持画面比例，用 RIFE 真正插帧到两倍帧数，再按基础帧率播放。检查实际帧数；若使用参考音频，也同步放慢。
3. **逐段生成**：绑定角色图、当前参考段和[参数化提示词](prompts/README.md)。除首段外，每段都从**紧邻前段已发布的慢速音视频尾部**续接，全片按顺序生成。
4. **检查与返修**：核对人物、服装、背景、动作、接缝，以及帧数和音轨。前段合格后再继续；重做前段会影响后续依赖。
5. **恢复原速**：先拼回同一制作段的慢速子段，去掉有记录的尾部填充，再按 2× 复原到源帧数。不要逐子段抽帧，也不要再次裁掉已移除的上下文前缀。
6. **回装与导出**：拼成全片，挂回完整源音乐。基础母版通过检查后，可选 RIFE 60fps、RTX VSR 3× 超分；最后核对解码帧数、音画同步和恒定帧率。

生成前的 RIFE 用于半速动作参考，生成后的 RIFE 用于提升交付帧率。只改 FPS 标签或重复帧，不能代替真实插帧。

## 参数与交付

历史基线：**1344×768、24fps、20 steps、`res_multistep` / `simple`**；原生 PyTorch Attention，未使用 Turbo LoRA、SageAttention 或 EasyCache。完整参数见 [profile.json](profile.json)（配方元数据，不可直接提交到 ComfyUI）。

保存成片、未超分原速母版，以及素材哈希、帧表、模型／节点版本、提交图、Prompt ID、Seed 和检查／返修记录。耗时与费用如实记录，未知项留空。

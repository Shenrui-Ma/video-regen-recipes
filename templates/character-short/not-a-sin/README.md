# XX不是罪过

原创配方：**Shenrui Ma（四倍体果蝇）**。

> 可以一句话开始：“用我喜欢的角色，做一支 XX不是罪过。”Agent 会准备角色图、检查模板素材与环境，再沿本地 H3 链路制作。

## 准备什么

- **角色想法即可**：说出角色、服装和想改的细节，不必先上传立绘。Agent 可按 [cowboy shot 角色图流程](references/character-image.md)自动准备参考图；也可直接使用你上传的图。
- **参考视频与音乐**：复用项目中已就绪的模板素材，或提供想复刻的视频。若模板素材尚未配置，Agent 只补问缺少的参考来源；本仓库不打包原片与音乐。
- **生成环境**：默认[本地 ComfyUI](../../../docs/comfyui-local.md)，也可连接[自托管远程实例](../../../docs/comfyui-remote.md)。还没有部署时，可让 Agent 协助配置。H3 的续接依赖见[工作流说明](workflows/README.md)。

## 两种入口

| 入口 | 你提供什么 | Agent 做什么 |
| --- | --- | --- |
| 文字起步 | 一句话角色与创作要求 | 准备或部署生图工具，生成角色参考图，再进入 H3 |
| 自带参考图 | 喜欢的角色图片 | 检查图片与服装，直接进入 H3 的参考生成流程 |

两种入口共用同一条制作链。文字起步会自动补齐中间图片；上传图片可以省去生图环节，视频仍需可用的 H3 环境。

## 制作流程

**角色准备 → RIFE 半速参考 → H3 串行续接 → 拼接并恢复原速 → 回装音乐 → 可选补帧、超分。**

1. 按源视频帧号分段，用 RIFE 制作真正的半速动作参考。
2. 绑定角色图与当前参考段，后续从**前段已发布的慢速音视频尾部**续接。
3. 每段检查人物、服装、动作、背景与接缝；失败段修好后再继续。
4. 先拼同一制作段的慢速子段，去掉记录中的尾部填充，再恢复原速与源帧数。
5. 拼成全片、挂回完整音乐，检查后按需补帧或超分。保留基础母版与运行记录。

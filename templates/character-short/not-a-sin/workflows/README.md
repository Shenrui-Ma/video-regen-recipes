# 本地 H3 运行契约

## 当前交付边界

这里记录历史制作实现的必要能力，不提供伪装成可运行工作流的 JSON。历史使用的 H3 CLI／Motion Context 适配代码尚未完成公共依赖打包、固定版本与干净环境验证；普通 ComfyUI H3 Ref2VA 图不自动获得此能力。不要编造一个 `continue-from` 官方节点、假定存在通用 CLI 命令，或静默退回独立片段生成。

`../profile.json` 是配方元数据，**不是 ComfyUI API 图**，不得提交到 `/prompt`。

公开完整执行包仍需补齐：

- 固定的 ComfyUI、H3 节点、续接实现、RIFE 实现及依赖版本；
- 权重／VAE／投影模型等实际文件选择与哈希；
- 参数化、去除私有环境依赖的 API 图与控制器；
- 两段真实续接测试，以及一套新角色的完整复现记录。

## 必须真正接通的数据

```text
角色图 ──────────────────────────────┐
当前参考视频 → 视频帧／可选参考音频 ───┤
本子段结构化提示词 ──────────────────┤→ H3 Ref2VA 条件
                                    │
上一子段已发布的慢速 video + audio   │
  → 对齐尾部 → VAE 重编码            │
  → 联合 AV Motion Context ──────────┘
                      ↓
   按采样网格创建 latent → 采样 → 保存 latent 与元数据
                      ↓
   解码 → 去除完整隐藏前缀 → 发布精确长度的 video + audio
```

第一子段没有上一段上下文。其他子段每次绑定新参考范围，同时绑定紧邻前一子段的已发布版本及 SHA。历史终版选择从视频／音频重建上下文，以避免取到超出发布终点的 latent 尾部；这与直接无损复用上一段 canonical latent 不同。

### 时序参数

此处是特定历史适配实现的合同，不是所有 H3 节点的统一接口：

- 基础 FPS：24；视频 context：22 帧。
- 历史 sidecar 中 `audio_context_frames=24` 是实现自己的音频上下文参数，不是 24 个 PCM 采样点。必须复核其时间映射代码，禁止照名字猜单位。
- 续接采样长度取不小于 `visible_frames + context_frames` 的最小 `17k+5`。
- `trim_frames = sample_frames - visible_frames`。
- `guide_start = trim_frames - context_frames`。
- `visible_frames=175` 时续接采样209帧，完整删去34帧隐藏前缀，context从位置12开始；首段175帧采样无前缀。
- `visible_frames=177` 的续接仍采样209帧，前缀为32帧；不能统一按34帧删头。

上述删头在**发布前**进行一次。组装已经发布的子段时不要再次删 context。另有真实源区间重叠时，依据源帧映射单独处理，二者不能混淆。

### 参考帧网格是另一项检查

采样长度合法，不代表所有输入参考帧已被节点采用。某些 H3 实现会对参考视频另做网格截断；尤其177帧输入必须核查实际进入条件的范围。保留源输入帧数、有效参考帧数、采样帧数、发布帧数四个值。不以终片帧数正确冒称逐帧参考完全保留。

## 最小接入与恢复流程

1. 只读检查设备、显存、模型、实际节点、队列和素材权限；选择用户授权资源。
2. 物化 API 图，验证所有节点存在，连线确实绑定预定的角色、当前参考与前段上下文。
3. 先跑生产尺寸下的短首段和真实续接段，分别校验采样成功、音画解码、context／trim与身份／接缝；试验不是完整成片。
4. `POST /prompt` 后立即持久化 Prompt ID 与图哈希，用 WebSocket 或 `/history/<prompt_id>` 跟踪。`0/N` 不代表第一步完成。
5. 保存失败、未知提交、成功和已验收等独立状态。连接中断先查 `/queue` 和 History，不重复付费或 GPU 提交。
6. 整链顺序生成；重试保留版本，复核后续依赖。关闭服务只针对本项目资源，不影响其他用户任务。
7. 所有基础片段完成后再独立进行媒体拼接和可选后期；生成结束不是交付完成。

历史基线使用自托管 Linux GPU 环境，但本次公开证据尚未闭合精确 GPU 型号、VRAM 峰值、全部 commit 和权重哈希。不要据此宣传消费级显卡最低门槛、速度或每分钟成本。

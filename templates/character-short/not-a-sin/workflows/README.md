# 工作流说明

本页记录历史实现要求，**尚无可直接导入的完整工作流**。H3 CLI／联合音视频 Motion Context 适配代码仍待打包、锁定版本和干净环境验证；普通 Ref2VA 图不能替代它，也不能退回独立分段生成。

公开执行包还需补齐：依赖版本、权重／VAE／投影模型文件与哈希、参数化 API 图和控制器，以及生产尺寸的两段续接测试、新角色完整复现。

连接与素材传输按[本地版（默认）](../../../../docs/comfyui-local.md)或[远程版](../../../../docs/comfyui-remote.md)处理；以下生成规则共用。

## 续接数据

角色图由[上游角色准备](../references/character-image.md)自动生成，或由用户上传；进入本节时它必须是已验收的真实图片。

```text
角色图 + 当前参考帧／可选音频 + 当前子段提示词 → Ref2VA 条件
上一段已发布的慢速音视频尾部 → 对齐 → VAE 重编码 → 联合 AV Motion Context
两者绑定 → 创建 latent → 采样并保存 latent 与元数据 → 解码 → 裁隐藏前缀 → 发布音视频
```

首段无前驱，之后全片串行；每段记录前驱版本与 SHA。上下文来自上一段**已发布的慢速音视频**，不取恢复原速后的片段或超出发布终点的 latent 尾部。这需要 VAE 重编码，并非无损 latent 复用。

## 采样与裁帧

以下仅适用于历史适配实现：基础 24fps，视频 context 为 22 帧。`audio_context_frames=24` 是实现内部参数，须核对时间映射代码，不能理解为 24 个 PCM 采样点。

- 续接采样帧数：不小于 `visible_frames + context_frames` 的最小 `17k+5`。
- `trim_frames = sample_frames - visible_frames`。
- `guide_start = trim_frames - context_frames`。

| 子段 | 可见帧 | 采样帧 | 隐藏前缀 | guide_start |
| --- | ---: | ---: | ---: | ---: |
| 首段 | 175 | 175 | 0 | 0 |
| 续接段 | 175 | 209 | 34 | 12 |
| 续接段 | 177 | 209 | 32 | 10 |

隐藏前缀只在发布前裁一次，不能统一删 34 帧。源区间重叠、尾部保持填充和复原速抽帧分别记账，见[时间线](../evidence/README.md)。

参考帧可能被节点另行按网格截断，尤其要检查 177 帧输入。分别保存**源输入、有效参考、采样、发布**四种帧数；输出长度正确不代表参考逐帧保留。

## 提交、检查与恢复

1. 检查设备、显存、模型、`/object_info` 与队列；物化 API 图，核对角色、当前参考、前段上下文连线。先用生产尺寸验证短首段及真实续接段的解码、裁帧、身份和接缝。
2. `POST /prompt` 后保存 Prompt ID、图哈希和实际提示词，用 WebSocket 或 `/history/<prompt_id>` 跟踪。断线先查 `/queue` 和 History，再决定重试；`0/N` 不代表首步完成。
3. 分别记录失败、提交结果未知、生成成功、验收通过。检查完整解码、帧数、音轨、哈希及画面；前段通过后才继续。
4. 重试保留旧版本并复核后续依赖。所有基础片段通过后再拼接、后期；运行结果放在用户项目中，服务操作仅限本项目资源。

精确 GPU、显存峰值、依赖版本和权重哈希待补；本地与远程说明是接入方式，不代表两个环境均已完成复现。

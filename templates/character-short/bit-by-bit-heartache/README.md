# 一点一滴刺痛我的心 （梦的翅膀受了伤）

**一句话，让 Agent 用你喜欢的角色制作这个视频。**

> “用我喜欢的角色，做一支《一点一滴刺痛我的心》（《梦的翅膀已经受了伤》）。”
>
> “把主角换成我上传图片里的角色，服装保持一致。”

说出角色或提供图片即可，Agent 负责准备参考图、生成视频、处理接缝、配乐和剪辑。没有指定角色、也没有提供图片时，才使用目录中的备用素材。

## 怎么用

让 Agent 读取 [SKILL.md](SKILL.md)，然后描述你想要的角色、服装或其他变化。不需要先手动准备整套素材。

**描述想法 → 准备角色 → H3 生成 → 剪辑配乐 → 成片。**

视频默认使用本地 ComfyUI + H3；环境未就绪时由 Agent 检查并协助配置。已有片段也可用于明确要求的重剪或换音乐。

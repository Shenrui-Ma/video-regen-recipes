# 从产品特点设计画面

先整理事实卡：产品名称、目标用户、使用场景、核心动作、结果、证据来源、尚未验证的主张。信息不足先读取已提供资料，避免凭产品名编功能。

## 主张如何变成镜头

| 产品特点 | 可以展示的变化 | 合适的叙事选择 |
| --- | --- | --- |
| 减少操作 | 同一个任务从多次操作变为少量步骤 | 并排对比，统一起点与结果 |
| 搜索 / 筛选 | 输入条件后噪声减少、匹配项定位 | 逐项淡出与共享元素移位 |
| 自动处理 | 一次触发带动后续状态，最后交付结果 | 事件链、路径流动、状态切换 |
| 可控 / 可追踪 | 改参数后对应效果变化，可回查来源 | 操作面板与结果联动 |
| 协作 | 多个贡献汇入同一成果，归属清楚 | 泳道、头像/标识、合流路径 |
| 实体结构 | 部件之间的关系、接口或空间优势 | 分层拆解、标注线、局部聚焦 |
| 设计 / 质感 | 材质、轮廓、细节随光照或视点变化 | 真实素材特写、遮罩显露、克制运镜 |
| 数据 / 结果 | 同量纲信息被清晰比较 | 图表生长、差异高亮；数字需有来源 |

表格是选择库，不是八镜头清单。每支影片通常只选择最能解释价值的两三种。

## 排序依据

已有认知的用户可直接看成果再解释操作；陌生用户先建立任务情境；复杂产品可跟随一次完整任务；实体产品可从外观进入结构。安装、远程部署或套餐页只有在本次传播目标需要时才出现。

每镜回答一个问题：观众应该关注哪里，什么发生了变化，这如何说明卖点。动作必须有前后状态；泛泛的漂浮卡片、不断增长的假数字和无目标镜头移动不能代替证据。演示数据可以说明流程，但要与真实测量区分，尤其是速度与效果对比。

## 空间与节奏

先看最大信息量时刻，再安排入场。字号依观看尺寸而定；手机上细小完整后台往往不如准确放大的关键区域。保留产品截图的比例与核心信息；遮盖真实敏感字段，保留正常产品文字。

在横屏使用并排关系，在竖屏使用纵向关系或先后替换。重排时同步更新箭头、字幕换行、停留长度和资产覆盖表；改变 viewport 不等于完成竖版。

稳定阅读状态与快速反馈交替。用户觉得慢，先删除重复信息、无意义启动黑场和多余装饰，再压缩过渡。背景可轻动，正在阅读的主体应稳定。角色、吉祥物和人物贴纸均为可选资产，有语义才出现，不默认贯穿全片。

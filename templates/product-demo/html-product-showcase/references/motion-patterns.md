# HTML 动画技巧库

所有进度来自统一时间 `t`。`p=phase(t,start,end)` 得到0–1，`out(p)` 用于快速反馈，`smooth(p)` 用于柔和连续变化。`motion.js` 只算数值，不操作 DOM 或启动时钟。取值必须每次完整写回，不能只在“第一次到达”时更新。

## 入场与注意力

**错峰入场**：同组元素按阅读顺序使用 `stagger(t,i,start,duration,gap)`，同时设置 `opacity=p`、`translateY((1-p)*distance)`。位移通常只需很短；段落正文不逐字飞入。多个卡片全展开后安排稳定停留。

**聚焦与弱化**：高亮一个实体，降低其他实体的强调度；保持位置，避免观众重新找内容。需要放大时根据目标框中心计算 translate/scale，并预算缩放后的外框；放大容器内的文字而不是把它裁到看不全。

**小幅弹性**：`scale=lerp(.96,1,backOut(p))` 可用于按钮响应或成果落位。backOut会超过1，过冲点也必须检查；长段正文、整屏UI和每个小元素不要同时弹。

## 因果与路径

**状态联动**：按钮触发、等待、完成标记、输出面板由同一组阶段边界计算。把它们写为状态函数，例如 `state=t<a?'idle':t<b?'working':'done'`，而不是分别 setTimeout。进度数字、填充条、状态标签在同一进度上取值；假数据标为演示。

**SVG 路径绘制**：先获取实际 `getTotalLength()`，设置 dasharray=L、dashoffset=L*(1-p)。运动点使用 `getPointAtLength(L*p)`，不另写一套直线插值。箭头和节点锚点来自 `getBoundingClientRect()`，转换到SVG坐标系；页面resize后重新计算。

**合流与分流**：用多条路径说明输入汇聚或任务分发。状态到达某节点后才点亮下一条，事件先于结果。复杂线路可拆时间段，避免一次把所有轨迹都画满。

## 对比与结构

**前后对比**：两个版本使用相同目标、画幅和尺度，可用遮罩显露结果，例如 JavaScript：`el.style.clipPath = 'inset(0 ' + ((1-p)*100) + '% 0 0)'`。分界标记与遮罩进度同步。不能让“之后”一侧偷偷换样本、放大或美化来制造差异。

**共享实体变形**：同一内容从列表项移动到详情或成果区时，保留id与视觉特征，在源框/目标框间插值位置和大小。复杂DOM不必把字逐点变形；可以容器移动、内部布局在清晰的交接点切换。文字缩放只用于短过渡，终态重新按目标字号排版。

**结构拆解**：SVG分组或CSS分层translate分别表示产品部件，标注线与部件锚点绑定。使用照片时可保留完整产品主图并用局部窗口揭示细节；没有分层素材不能把随意切片冒充真实内部结构。

**图表与数据**：图形生长、数字滚动、差异标注应共享数值源和坐标标尺；设置 `font-variant-numeric:tabular-nums` 避免数字抖动。先让观众看懂单位和对比对象，再强调结论。动画速度不表示产品实际耗时。

## 场景连接

硬切适合明确换问题；短溶解适合视觉连续；遮罩或共享实体适合保持因果关系。离场与下一镜入场可以重叠，但不能吞掉关键阅读或旁白区。

单HTML里，按时间线给每个场景设置局部时间与显示状态，离开的场景明确隐藏且停止拦截点击。不要再叠FFmpeg同一段转场。多HTML输出才在后期合成；共享剪辑器只支持统一转场长度，逐边不同长度需另写可核验的合成图。

**选择准则**：先写“这个动效帮助观众理解什么”，说不清就删除。新产品先选一两种主要手法，不要求把本页技巧全部使用。

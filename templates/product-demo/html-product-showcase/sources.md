# 来源与验证

整理：**Shenrui Ma（四倍体果蝇）**。

主要参考作者提供的 `html-motion-production-v0.1.1.zip`（包内声明MIT），包括设计方法、生产链、确定性时间骨架和逐帧渲染脚本。本模板保留其时钟、几何和音画时序方法，重新整理为按产品特点选择动画的Skill。

`scripts/render-film.cjs` 由该包渲染器改编，增加本地资源约束、输出锁、临时文件隔离、无覆盖发布、帧率核验与父级透明度计算。`motion.js`、产品叙事文档、分镜编译器及示例重新编写，面向不同产品和展示目标复用。

旧案例记录了横竖屏重排、箭头对齐、字幕占位、真实录屏前导和JS/CSS时钟不同步等问题；这里将其转化为通用方法，不沿用固定分镜或声称旧成片使用了本模板的新代码。

验证范围：源包CRC、文档与代码读取、JSON / Python / JavaScript语法、时间线与动效函数的离线测试、相对链接与公开内容检查。**本次未生成产品素材、渲染MP4或做视觉验收**；浏览器、字体、复杂素材和音频合成仍需在实际制作时验证。

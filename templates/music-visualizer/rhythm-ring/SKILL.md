# 律动环 MV

## 1. 确认母带和独立项目

已有音频就直接开始，不要求先执行翻唱模板。用户想换歌声音色时，可先转到[少女乐队 DDSP 翻唱](../../singing-cover/girls-band-ddsp/SKILL.md)；它不是此模板的依赖。

沿 [README](README.md)检查 Python + Pillow、FFmpeg / ffprobe 和可用字体。以用户认可的最终音频为准，核对全曲或节选；记录素材来源、图片/字体许可与母带 SHA-256。缺少指定音频/角色图时明确说明，不下载参考作品当作用户输入，不擅自复用私有素材。

## 2. 填写并校验项目

将 [examples/project.json](examples/project.json) 作为独立项目请求，绑定实际文件。默认 1080×1920 / 60 fps；横屏可用 1920×1080，不根据参考片名臆测时长。保留音频原混音，不自动归一化或加 BGM。

歌词先核对原文与翻译，再对最终输出区间制作 `cues`；一至两行、按时间排序、互不重叠。不得直接套用旧音频的 cue；没有歌词输入时可先做无字幕版本。只改字幕/图片不会重新调用音色模型。

从仓库根执行 `python3 templates/music-visualizer/rhythm-ring/scripts/render.py <project.json> --check`。失败时修正明确字段，不删除 SHA 检查，不延长音频来掩盖越界。全局音量极低时先让用户确认母带，不通过虚假满幅动画冒充节奏。

## 3. 短预览与最终渲染

先用独立版本 JSON 和输出文件生成包含安静段、强拍、字幕切换的短预览，人工看图片完整性、环与人脸关系、文字适配和中日韩字形。短片的 cues 要随节选起点重映射，不能直接保留超界全曲 cue。

确认后按同一配置恢复目标全长，运行不带 `--check` 的命令。记录里区分合成测试、真实音频渲染和人工验收；不把“完整解码通过”写成“画面/歌词已正确”。异常只重做这个 MV 输出，新版本另存，不重跑翻唱、覆盖母带或改其他项目。

## 4. 交付

交付 MP4、项目 JSON、render 记录、使用的 cue 与原母带引用。告知 AAC 重编码、源节选范围及尚未检查的部分。用户请求发布前，不上传成片。

来源与示例见 [sources.md](sources.md)。这是资料包方法的独立双环实现，原片渲染工程未完整恢复；不声称 FFT 频谱、逐鼓点检测或原片像素级复刻。

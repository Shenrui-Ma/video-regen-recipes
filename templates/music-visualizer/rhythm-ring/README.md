# 律动环 MV

给一份已经确认的音频和图片，生成随音乐强弱变化的双环 MV，可加标题、署名和一到两行歌词。**音频可以来自翻唱、原创、人声录音或其他合法来源，不要求安装 DDSP、ComfyUI 或 H3。**

## 成品参考

- [𝑺𝑻𝑨𝑹𝑩𝑶𝒀 高松灯](https://www.bilibili.com/video/BV1BPgq6hEey/)
- [𝑩𝒊𝒍𝒍𝒊𝒆 𝑱𝒆𝒂𝒏 —— 千早爱音](https://www.bilibili.com/video/BV1dQKY6ME3t/)

成品与制作配方来自四倍体果蝇 / Shenrui Ma。两支作品也展示了[少女乐队 DDSP 翻唱](../../singing-cover/girls-band-ddsp/README.md)的声音效果；想换音色才使用该模板，已有母带直接从这里开始。

**复现边界：**资料包保留了历史成片和部分后期记录，但旧 MV 脚本、cue 和全部素材没有找全。这里提供独立、可运行的双环实现，不把它冒充原渲染工程，也不承诺与上述视频逐像素一致。[来源与验证](sources.md)。

## 输入与效果

需要已确认母带、获准使用的图片、覆盖所需语言的本地 TTF/OTF 字体；歌词可选。默认 1080×1920、60 fps，亦可用 1920×1080。图片等比完整放入画面，不自动生图、不做口型、不改原混音。

两个环分别使用**全频和 180 Hz 低通的立体声 RMS 能量包络**改变半径和线宽，带快速响应和缓慢回落。它响应真实音频强弱，但**不是 FFT 频谱，也不推断 BPM 或每个鼓点**。静音时环静止，极低底噪不会被放大成满幅跳动。

标题在上方，环在画面中部，歌词在下方。可换音乐、图片、文字、两环颜色、画幅、帧率和节选；对特殊构图先出短预览，确认环没有挡住脸或重要信息。

## 运行

Agent 读取 [SKILL.md](SKILL.md)。下面命令在仓库根目录运行，Python 环境沿用仓库已有的 Pillow 依赖，另需系统 FFmpeg / ffprobe。

1. 把 [project.json](examples/project.json) 放入独立用户项目，填入 `audio`、`image`、`font`。所有相对路径以项目 JSON 所在目录为基准，而非仓库或当前终端目录。
2. 计算最终母带的 SHA-256，写入 `audio_sha256`。示例占位符会被明确拒绝，不能当作完成校验。
3. `start` 为从原音频截取的位置；省略 `duration` 使用剩余全部音频，最多一小时。只有用户要求节选才填写时长；不自行套用原作品的 81/111 秒。
4. 先校验，再渲染到新版本文件：

```bash
python3 templates/music-visualizer/rhythm-ring/scripts/render.py /path/to/project.json --check
python3 templates/music-visualizer/rhythm-ring/scripts/render.py /path/to/project.json
```

`--check` 读取文件、核对母带哈希、探测音轨时长、校验字体与字幕区间，但不渲染；容器未提供音轨时长时会解码音频测量，不能用更长的视频时长代替。`start` 相对所选第一条音轨的起点。渲染使用临时目录内经过哈希核对的母带副本，所有分析与封装共用同一份字节；输出 `MP4 + 同名.render.json`，已有目标或记录一律拒绝覆盖。

`cues` 使用**输出片段的相对秒数**，双语放在同一 cue 的两行中；区间按 `[start,end)` 生效，不允许重叠、倒序或超出成片。例：

```json
{"start": 1.2, "end": 3.8, "lines": ["已核对的原文", "已核对的译文"]}
```

字幕不是 SVC 输入。改了母带、剪辑起点或时长，必须重新听审时间轴；脚本不会替你翻译、ASR 或沿用旧歌词缓存。

## 交付与检查

- MP4 使用 H.264 / yuv420p，音轨编码为 AAC 48 kHz 双声道，不额外调增益、变速或混入 BGM。**AAC 不是无损音频**，原母带应单独保留。
- 记录绑定项目、音频、图片、字体及输出哈希，保存起点、时长、帧率、实际帧数、cue、耗时与完整解码检查。
- 人工看头尾、强拍和字幕切换帧，听有无人声截断、漂移、爆音；字体缺字方框与角色遮挡不能靠 ffprobe 发现。脚本的 `visual_review` 默认是 `not_performed`，不能自动改成已验收。
- 本次只用自制合成音频与测试图片验证，未下载这两首歌、未复刻整支作品、未重新跑 GPU 翻唱。具体测试命令见 [sources.md](sources.md)。

# 从一句想法到六段剧情

这里的“文生番剧”是文字驱动完整制作：文字 → 分镜与资产 → H3 Ref2VA → 剪辑。角色一致性仍需真实参考图与声音；仅一段文字不能取代这些输入。

## 1. 先确定五件事

作品与出场角色、剧情一句话、发生地点、对白语言、交付时长／比例。用户没有特别要求时，可用六段约一分钟、日语对白、中日双语字幕；明确告知这个起步设置。服装按选定参考保持一致，不把不同阶段的设定混用。

只用故事所需的人物。五位角色可以分段出场，前几段每镜 2 人、1–2 人说话，最后再安排稳定的合景。演奏、多人跑动、近景手指和快速切镜会增加检查与返工成本，初次制作先少用。

## 2. 六段各完成一件事

| 段 | 剧情作用 | 默认帧数 / 24fps | 分镜重点 |
| --- | --- | --- | --- |
| 01 | 引出问题 | 243 / 10.125秒 | 交代人物、物件和视线 |
| 02 | 让误会或压力出现 | 243 / 10.125秒 | 一次简短回应 |
| 03 | 揭示真实意图 | 243 / 10.125秒 | 一个动作和表情变化 |
| 04 | 关系发生变化 | 243 / 10.125秒 | 明确谁先说、谁后回应 |
| 05 | 做出共同决定 | 243 / 10.125秒 | 进入结尾前的动作准备 |
| 06 | 留下余韵 | 226 / 9.416667秒 | 稳定收尾，留足句尾 |

总计 1441 帧，约 60.041667 秒。分段名对应一次生成任务；它不同于提示词内部的 `[Shot N]`。默认每任务一个主要机位，进阶时才在一个任务里增加切镜。调整时长必须同时调整帧数、对白密度、预期片长和后期清单。

## 3. 填写 episode.json

复制任一[示例](../examples/)到自己的项目，然后修改：

- `characters`：每人的名称、从图片观察得到的英文 `appearance`、身份图、三视图、参考声音路径。不要凭印象填写外观；原文没有的背面细节标为生成补全。
- `scenes`：场景的英文描述和参考图路径。相同房间优先复用一张母版。
- `model_files`：执行实例实际 loader 枚举中的 H3 文件名。占位符必须替换；模型来源与版本另记到项目资产账本。
- `shots`：人物 `cast` 按本段固定顺序，`visual_description` 用英文和 `@角色ID` 指向人物；构建器自动改成对应 Subject 编号。
- `dialogue_language`：默认 `Japanese`，构建器也支持 `English`、`Chinese`；台词原文与标签保持一致。
- `dialogue`：按真实发声顺序排列，`character` 指向角色 ID，`text` 用目标语言，`delivery` 用简短英文说明语气。不要手写 Audio 或 S 编号。
- `frames`、`seed`：显式保存。种子只是可比较的条件，不保证跨硬件版本复现同一画面。

两份示例的故事与台词都是新写的练习素材，尚无对应生成成片；它们不表示官方人物关系或剧情走向。

## 4. 每段检查清单

- 能说清左右位置、面朝方向、景别和单一主动作吗？
- 谁先开口，谁保持闭嘴，结束时人物和道具停在哪里？
- 上一段结尾与下一段开头的服装、场景、视线方向是否相容？
- 对白能自然说完吗？可先朗读计时或做临时读稿；读稿不是本路线最终配音。过长先缩句或拆段，不靠加速成片塞台词。
- 姓名和特殊读音是否核对？必要时在生成对白中用正确假名，字幕仍按实际话语整理。

## 5. 项目目录

```text
project/
├── episode.json             # 当前剧情与参数
├── bindings.json            # 已导入 ComfyUI 的输入映射
├── assets/
│   ├── characters/<id>/     # identity.png、turnaround.png
│   ├── voices/<id>/         # reference.wav
│   └── scenes/<id>/         # reference.png
├── build-v1/                # 构建器输出的提示词、API图、清单
├── runs/                    # 每段每版运行记录与原片
├── edit/                    # 选用版本、字幕、音乐和剪辑中间件
└── exports/                 # 基础母版、字幕版、可选增强版
```

素材路径相对 `episode.json`，输出使用新版本目录。不要在模板安装目录生成文件，也不要覆盖已有成片或已提交任务的配置。

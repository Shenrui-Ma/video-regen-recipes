# 效率、返修与进阶

## 先减少无效生成

1. 角色身份图、三视图、声音和常用场景按哈希复用；模型放在执行主机，避免每段重复下载。
2. 第一次用基础尺寸完成一段全链路，包含解码、下载、看图、听对白。不要只看采样开始就批量投递。
3. 默认单段串行，减少资源竞争；准备字幕、素材或剧本可在独立资源上并行。增加 GPU 并发前检查剩余显存、RAM 和任务归属，不照搬作者机器配置。
4. 保留已验收片段。预览检查用基础原片，可选增强只对选用版本做；最终字幕合成也晚于片段确认。
5. 每次返修改变一个主要因素，记录原输入、改动、种子和结果；一个重复失败应回到输入或设计排错，不能无限抽卡。

## 修改影响哪些产物

| 修改 | 需要重新检查或生成 |
| --- | --- |
| 单段对白、表情、动作或 seed | 该段视频／对白、该段 ASR 与字幕、总片拼接与导出 |
| 某角色身份或服装图 | 使用该图的所有片段 |
| 某角色音色参考 | 该角色实际发声的片段 |
| 某场景图 | 使用该场景的片段 |
| 模型、节点或全局采样配置 | 全部片段，先验证第一段 |
| 字幕样式或翻译 | 字幕及合成版，保留生成原片 |
| BGM 音量或增强规格 | 相应后期版本，保留基础母版 |

本模板各段独立生成，重做单段不会自动使其他段 latent 失效；仍要检查新段前后接缝。帧数发生变化时，后续字幕绝对偏移也要重算。不要套用其他模板的整链 Motion Context 返修规则。

## 常见失败

- **人物或声线互换**：先核对每段的 Subject / Picture / Audio / S 映射与实际输入。角色 ID、表格顺序和文件名看起来相同不代表节点绑定正确。
- **背景变形、越位**：减少同时动作和机位变化，补清楚左右位置与遮挡。需要构图参考时按资产说明生成角色化参考图。
- **名字读错或句尾截断**：核对发声人、假名和句子长度；重做该段，不以字幕掩盖实际错读。
- **显存不足**：检查其他任务、模型精度与设备兼容，先保持 batch=1。降低分辨率或换量化版本须明确记录；不能把未验证的配置当作同一基线。
- **图已生成但本地没文件**：从本段任务 ID 的 History 恢复和下载，不能重新提交或取全局“最新视频”。

## 进阶分支

| 分支 | 何时用 | 必须保留的边界 |
| --- | --- | --- |
| 八段戏剧版 | 对话转折多，单段想更短 | 历史节奏为 175×7+226 帧；重新设计八段，不能只换拼接器 |
| 高清动作版 | 基础版已通过，希望更清晰或更复杂动作 | 历史画布 1088×608，20步；重新生成，不是把低清片放大 |
| 空间参考 | 多人相对位置难控制 | 坐标→布局图→角色化构图图→普通 Ref2VA 参考，属于软条件 |
| 后期超分 | 已接受基础原片，交付需要更大尺寸 | 与 H3 原生规格分开记录；超分不修复错脸或错台词 |
| 修脸／连续 latent | 有明确问题且愿意做新实验 | 不属于本包已验证路线，另建分支、先做短片测试 |

硬首帧／尾帧和指定时间戳中间帧需要另外的节点契约；本包 API 图只有一般参考输入。不要只在 prompt 里写“锁定首帧”就声称已经接通硬控制。

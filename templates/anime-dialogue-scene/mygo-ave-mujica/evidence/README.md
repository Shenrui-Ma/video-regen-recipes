# 验证范围

## 历史记录提供了什么

贡献者的制作指南报告了四条独立分支。它们不能混成一条制作记录：

| 分支 | 片段数 | 原生画面 | 记录中的结果 |
| --- | ---: | --- | --- |
| 基础版 A | 6 | 768×448、24fps | 243×5+226，共1441帧，约60.041667秒 |
| 剧情版 B | 8 | 768×448、24fps | 175×7+226，共1451帧，约60.458333秒 |
| 高清动作版 C | 8 | 1088×608、24fps | 独立重生成；另有3×超分交付记录 |
| 空间试验 D | 3 | 高清动作片段的重做分支 | 仅后三段，没有证明已合入C的全片 |

四条分支都是独立 Ref2VA 联合音视频采样后剪辑；没有前段 AV latent 传递或硬首尾帧输入。空间图作为普通参考输入。

指南报告曾核对图、History、素材哈希和成品元数据；本次只读取该指南与其中的 API 数据，未取得全部原始产物重新验证，也未重新看完视频或听审声音。

## 本包新增和改变了什么

- 从附录 API 数据整理通用节点结构，替换私人输入、输出位置和历史随机种子；不发布原始任务图与记录。
- 将人物、场景、声线、对白和模型名称参数化，并为弱能力执行模型写明检查条件。
- 提供两份新写剧情计划。它们继承基础采样规格，不是历史影片的逐帧复刻，也没有对应已验收样片。
- 增加本地构建、单段提交与恢复工具，以及隔离项目和版本的规则。这是公开化后的实现，须在用户实际环境再次验证。

## 如何验证公开版

在模板目录执行离线测试；不需要模型、账号或 GPU：

```bash
python3 -m unittest discover -s tests -v
```

本次通过 63 项离线测试：构建器 21 项、运行器 35 项、拼接工具 7 项，包含两份示例计划的完整构建与合成媒体拼接。检查覆盖字段、角色与音频顺序、帧数、引用、错误输入、单次提交、恢复及明显短音轨拒绝。它们不证明 H3 推理质量、声线相似或字幕准确。

实际部署仍需记录四类证据：① 模型／节点版本与设备；② 第一段完整生成及技术检查；③ 逐段画面与声音验收；④ 最终成片的帧数、字幕与音画同步。

待补的关键项是固定的完整运行环境、权重哈希、真实资源消耗、新环境全片复现和 Ave Mujica 的资产／声音／成片验收。可选人脸修复、硬关键帧和跨段 latent 续接不属于本包已经验证的能力。

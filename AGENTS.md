# Repository instructions

- Keep the main README concise and general. List individual recipes in the template catalog.
- Public recipes must not contain private paths, host details, credentials, personal network configuration or private character presets.
- Default to local ComfyUI. Keep remote connections and file transfer separate from generation logic.
- Distinguish historical evidence, offline checks, live inference and visual/audio review.
- Use Angular-style commit subjects: `type(scope): summary`, for example `feat(templates): add an episode recipe`.
- Use a concise imperative summary. Typical types: `feat`, `fix`, `docs`, `refactor`, `perf`, `test`, `build`, `ci`, `revert`.
- Commit bodies may explain the reason, validation and remaining limits. Never claim live validation from offline tests.
- Attribute original work to **Shenrui Ma（四倍体果蝇）**. Do not publish the author’s Chinese legal name.

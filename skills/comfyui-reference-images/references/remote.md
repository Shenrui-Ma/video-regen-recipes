# 远程版：连接与传输

适用于用户自己的远程 ComfyUI，生成逻辑仍走[执行与恢复](execution.md)。托管平台可能使用不同 API，不能直接套本页。

1. 从用户提供的连接配置取得 `COMFY_BASE_URL`；认证交给已有凭据管理器或运行时环境。不要猜服务器、扫描其他机器，或把认证写入图。
2. 用 `GET /system_stats`、`GET /object_info`、`GET /queue` 验证目标实例。地址中出现 `127.0.0.1` 也可能是用户已建立的转发，不能据此断言 GPU 在本机。
3. 明确两个空间：Agent 侧 `PROJECT_DIR`；执行主机上的 ComfyUI 模型、input、output 目录。下载到 Agent 本机的模型不会自动出现在服务器。
4. 输入图优先通过 `POST /upload/image` 上传。若使用用户已有文件传输工具，分别核验源和目标文件 SHA-256，再使用服务器返回或识别的相对名称。
5. 模型尽量在执行主机下载；需要中转时保留同一份模型清单，目标校验大小和 SHA-256 后再进入模型目录。API-only 连接不能假装拥有服务器文件管理权限。
6. 输出优先经 `GET /view` 下载到 Agent 侧项目，按 history 的 `filename/subfolder/type` 定位。能读服务器文件时额外比较两端哈希；不能读时仅报告已完成的下载/解码校验。
7. 网络断开保留任务记录；连接恢复后查相同 `prompt_id` 的 queue/history。先区分连接问题与推理错误，再决定是否重跑。

通过条件：API 可达、模型位于执行主机并被识别、输入可上传、输出可取回。连接方式不改变模型、提示词、seed 或工作流。

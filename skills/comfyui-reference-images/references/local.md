# 本地版：连接与文件

本页只解决环境连接。图的准备和生成统一走[执行与恢复](execution.md)。

1. 使用已有 ComfyUI；从用户配置或正在使用的实例确定地址。未指定时先探测 `http://127.0.0.1:8188`，不要假定桌面版使用同一端口。
2. 请求 `GET /system_stats`、`GET /object_info`、`GET /queue`。确认返回 JSON，而非登录页或 HTML 错误；只记录必要设备能力，不公开原始系统信息。
3. 不可达时，检查用户指定的安装方式、端口和启动状态。若需要安装，先按[官方本地说明](https://docs.comfy.org/installation/system_requirements)确认设备支持及依赖，不盲装节点包或覆盖现有环境。
4. 定义运行时变量：`COMFY_BASE_URL`、执行主机上的 `COMFY_ROOT`、用户项目 `PROJECT_DIR`。它们不是需要写进模板的固定值。模型目录、剩余磁盘和节点信息都以该实例为准。
5. 输入图可经 `POST /upload/image` 上传，或复制进该实例实际 input 目录。不要把任意本地绝对路径填进 `LoadImage.image`；使用服务识别的相对名称。
6. 输出按本任务 history 中指定的输出节点取回。即使能直接读 output 目录，也不要按“最近的 PNG”猜结果。

通过条件：服务可达、API 类型正确、节点和模型可盘点，项目可写，能够提交任务并取回文件。仅打开网页不代表这些条件成立。

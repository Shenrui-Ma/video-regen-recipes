# 参考图与提示词

先确认图像用途，再写主体、动作、构图、光线和保留项。使用清楚的自然语言，参考图承担外观证据；避免仅堆角色名、形容词或互相冲突的约束。多图需要指定各自职责。[官方提示词指南](https://developers.openai.com/api/docs/guides/image-prompting)

## 参考图分工

| 用途 | 控制什么 | 不默认控制什么 |
| --- | --- | --- |
| 身份 | 脸部、发型、配色、标志性配饰 | 背景、原姿态 |
| 服装 | 当前镜头的服装与配件 | 人物身份 |
| 场景 | 布局、镜头视角、光线 | 场景中人物的身份 |
| 姿态 | 动作方向、身体关系 | 脸、服装和画风 |
| 风格 | 线条、材质、色彩表现 | 角色、构图和内容 |

按任务需要选择最少的清晰参考，不为凑数量添加图片。沿用角色时保留原始身份锚点；已生成画面只有在本任务明确用于延续构图或局部编辑时才作为补充，避免不断用上一张代替身份锚点。

## 通用提示词骨架

下列是模板，需要填完并删除不用的段落再提交。客户端会在图片前补充序号与用途；确保正文序号一致。

```text
Create one reference image for {{PURPOSE}}.
Image 1 defines the character identity: {{VISIBLE_IDENTITY_FEATURES}}.
Image 2 defines {{SECOND_REFERENCE_ROLE}} only.
Show the character {{ACTION}} in {{SCENE}}.
Use {{SHOT_SCALE}}, {{CAMERA_ANGLE}}, and {{COMPOSITION}}.
Keep {{IDENTITY_AND_OUTFIT_INVARIANTS}} consistent.
Render with {{VISUAL_STYLE_AND_LIGHTING}}.
Change only {{ALLOWED_CHANGES}}. The deliverable is one standalone image.
```

如果只有一张参考，删除 Image 2 一行；不要虚构不存在的附件。尺寸和质量由调用参数设置，正文只补充构图意图。

## 三种常用任务

- **角色参考**：明确正面／侧面或全身、清楚的服装轮廓和简洁背景。默认分别生成单张；只有模板要求时才做多视图拼板，并检查各视图是否同一角色。
- **首帧／尾帧**：分别写可见动作状态，不把“走进房间、坐下、又站起来”塞进单张图。两张共用角色、服装、环境、镜头方向，说明变化点。图片相似不代表视频已能连续运动。
- **角色放入已有场景**：场景参考控制空间、透视、遮挡和光照；角色参考只控制人物。需要保留摄影背景时，把动漫线条要求限定到人物，避免全画面被重绘成同一风格。

例如：以参考图 1 的角色为主角、参考图 2 的门廊为环境，生成中景起始帧。人物站在门外，右手刚抬向门把手；服装不变、傍晚侧光、门朝画面右侧打开。另一个尾帧任务只把动作改为“门已打开，人物迈过门槛”，其他设置保留。

修订时读取已保存的提示词，只改变一项明确变量并记录差异。关键文字需要精确排版时，可另做有记录的合成版本；不要把拼接图当成模型原始输出。

# 输出验收与记录

每次生成使用独立目录，保留输入清单、原始提示词、实际参数、状态和输出，避免与其他任务串图。

客户端自动写入 `prompt.txt`、`manifest.json`、`response.json`（若已收到，内含请求指纹、响应哈希与原始响应）和 `image.png`。运行目录可能包含完整提示词、参考图内容及生成图，只保存在用户工作区，不加入公共仓库或直接粘贴到日志。

| 字段 | 记录内容 |
| --- | --- |
| 请求 | 入口、语言模型、图像模型、quality、请求尺寸、请求指纹 |
| 参考 | 顺序、用途、实际文件哈希；用户本机路径只用于本机运行 |
| 返回 | request／response／image call 标识、原始响应可用字段、修订提示词 |
| 原图 | 文件名、实际尺寸、字节数、SHA-256 |
| 检查 | 技术检查、人物／服装／姿态／场景检查及未通过项 |
| 修订 | 相对上一版改了什么、是否生成新图、是否做后期 |

客户端检查 PNG 结构与校验和，不证明图片审美、人物一致性或所有解码器可读。用宿主图片查看工具实际打开输出；没有查看能力时明确留待检查。若要求固定尺寸但返回不符，原图保留，状态为待修复，不自动裁剪。

生成成功与交付成功分开记录。用户未看到图时，优先重新展示已有文件；不要因此重新调用生成接口。费用以实际使用量和账单为准，没有数据就标未知。
